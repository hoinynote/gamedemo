# Plan: Rope Control Improvements

## Goal

Improve the two-player rope controls in the Canvas game. While a rope is stretched and attached, holding W or ] applies a substantially stronger pull. Rope launches use the launch-time directional input for eight-way aiming. Players can rebind all six controls, save those bindings in the current browser, and choose a physical-key combination their keyboard can register reliably.
