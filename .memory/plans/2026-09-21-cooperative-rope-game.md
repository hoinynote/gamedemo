# Plan: 협동 로프 점프 게임

## Goal

브라우저에서 `index.html`을 열어 즉시 플레이할 수 있는 2D 횡스크롤 협동 로프 게임을 구현한다. 두 플레이어가 한 키보드로 이동하고 서로에게 로프를 발사해 장력을 이용하며, 3개 스테이지를 클리어할 수 있어야 한다. 브라우저 뒤로가기·탭 전환·페이지 이탈 시 현재 게임 상태를 체크포인트로 저장하고 게임을 일시정지하여, 복귀 후 진행 상태가 초기화되지 않도록 한다.
