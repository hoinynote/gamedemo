# Decisions: Tugmate Controls Help

- Date: 2026-10-20
- Status: Confirmed from the user's request and prior UI discussion

## D01. 조작 설명 위치와 내용
- **Chosen**: 기술 안내는 조작 키를 설정하는 화면에 표시한다. 물리 키 코드 입력, 플레이어별 키 변경, 브라우저 저장, 중복 키와 예약 키 거부를 설명한다. 기존 `기본값 복원` 버튼은 그대로 둔다.
- **Rationale**: 설명이 필요한 기능을 실제 설정 흐름 안에서 바로 이해할 수 있다.

## D02. 게임 메뉴 표시 이름
- **Chosen**: 메뉴 상단의 `ROPEBOUND DUO`를 `터그메이트`로 바꾼다.
- **Rationale**: 사용자가 정한 게임 이름을 브라우저 제목과 게임 화면에서 일치시킨다.
