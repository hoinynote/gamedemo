# Decisions: 협동 로프 점프 게임

- Date: 2026-09-21
- Status: Confirmed

## D01. 실행 환경
- **Chosen**: 브라우저에서 바로 실행되는 단일 HTML/CSS/JavaScript + Canvas 게임
- **Rationale**: 별도 설치 없이 즉시 플레이할 수 있고, 외부 게임 엔진 없이 핵심 로프 메커니즘을 직접 구현할 수 있다.

## D02. 게임 장르와 화면
- **Chosen**: 2D 횡스크롤 플랫폼 게임
- **Rationale**: 좌우 이동, 점프, 로프 장력을 결합해 협동 이동의 재미를 직관적으로 보여준다.

## D03. 플레이어 조작
- **Chosen**: P1은 `F/H` 좌우 이동, `T` 점프, `G` 아래로 내려가기/플랫폼 통과. P2는 좌우 방향키 이동, 위쪽 방향키 점프, 아래쪽 방향키 플랫폼 통과.
- **Rationale**: 한 키보드에서 두 플레이어가 서로 겹치지 않는 영역을 사용하며, 플랫폼 게임에 필요한 중력 기반 이동을 지원한다.

## D04. 로프 발사 방향과 연결
- **Chosen**: 각 플레이어가 바라보는 방향으로 로프를 발사하고, 로프가 상대 플레이어에게 맞으면 연결된다. 벽이나 장애물에 막히면 연결되지 않는다.
- **Rationale**: 상대 위치를 고려한 조준과 지형 기반 협동을 만든다.

## D05. 로프 조작 키
- **Chosen**: P1은 `Q`로 로프를 발사하거나 연결 상태를 해제하고 `W`로 연결 중 장력을 강화한다. P2는 `[`로 로프를 발사하거나 해제하고 `]`로 장력을 강화한다.
- **Rationale**: 발사·해제와 장력 강화의 역할을 분리해 점프 타이밍을 협력적으로 조절할 수 있다.

## D06. 로프 물리
- **Chosen**: 연결된 로프는 최대 길이를 가지며, 두 플레이어가 멀어져 최대 길이를 넘으면 장력이 발생한다. 장력은 플레이어의 이동과 점프를 보조해 더 높거나 멀리 도약하게 한다.
- **Rationale**: 사용자가 요청한 '서로에게 줄을 발사하고 장력으로 도약하는' 핵심 상호작용을 구현한다.

## D07. 로프 해제
- **Chosen**: 발사 키를 다시 누르면 연결이 해제된다.
- **Rationale**: 플레이어가 도약 순간을 직접 제어할 수 있다.

## D08. 스테이지 수와 진행
- **Chosen**: 튜토리얼, 기본 로프 퍼즐, 복합 장애물 퍼즐로 구성된 3개의 짧은 고정 스테이지. 클리어 후 자동으로 다음 스테이지로 진행한다.
- **Rationale**: 핵심 조작을 단계적으로 학습시키면서 초기 구현 범위를 관리한다.

## D09. 클리어 조건
- **Chosen**: 두 플레이어가 함께 출구에 도착해야 스테이지를 클리어한다.
- **Rationale**: 한 명만 먼저 도착하는 것을 막고 협동을 필수 요소로 만든다.

## D10. 장애물과 퍼즐 요소
- **Chosen**: 플랫폼, 낭떠러지, 가시, 벽, 스위치, 움직이는 발판, 중량 상자, 당겨지는 문, 출구
- **Rationale**: 로프 장력 점프와 오브젝트 상호작용을 함께 활용하는 다양한 협동 퍼즐을 구성한다.

## D11. 실패 처리
- **Chosen**: 플레이어가 낭떠러지나 위험 장애물에 닿으면 두 플레이어 모두 시작 지점으로 돌아가 현재 스테이지를 재시작한다.
- **Rationale**: 실패 후 재도전 흐름을 단순하고 빠르게 유지한다.

## D12. 카메라
- **Chosen**: 두 플레이어를 함께 따라가는 횡스크롤 카메라
- **Rationale**: 두 플레이어가 화면에서 분리되지 않도록 하고, 로프 연결 상태를 계속 확인할 수 있게 한다.

## D13. 시각 스타일
- **Chosen**: 밝고 선명한 2D 벡터 스타일
- **Rationale**: 플레이어, 로프, 장력, 장애물의 상태를 Canvas에서 명확하게 표현할 수 있다.

## D14. 시작과 재시작 흐름
- **Chosen**: 시작 화면에서 `Enter`로 시작, `R`로 현재 스테이지 재시작
- **Rationale**: 게임 시작 전 조작법을 안내하고, 반복 도전을 빠르게 할 수 있다.

## D15. 사운드
- **Chosen**: 외부 파일 없이 Web Audio 기반의 간단한 효과음 사용
- **Rationale**: 로프 발사·연결·장력·점프·실패·클리어 피드백을 제공하면서 자산 관리를 단순하게 유지한다.
