# Decisions: Rope Control Improvements

- Date: 2026-09-25
- Status: Confirmed

## D01. 강한 당기기
- **Chosen**: P1은 `W`, P2는 `]`를 누르는 동안 연결된 로프의 당기는 힘을 기존보다 강하게 한다. 당기기는 로프가 팽팽해진 상태에서만 작동하며, 힘은 로프 양쪽 플레이어에 반작용으로 적용한다.
- **Rationale**: 기존 장력 동작을 유지하면서 상대를 더 강하게 끌어당겨 멀리 또는 높이 움직일 수 있도록 한다.

## D02. 로프 조준
- **Chosen**: 발사 순간 각 플레이어의 상하좌우 입력 조합을 읽어 8방향으로 발사한다. 수평 방향 입력이 없으면 플레이어가 바라보는 방향을 사용한다.
- **Rationale**: 별도 조준 모드 없이 이동 입력으로 위·아래와 대각선 조준을 할 수 있다.

## D03. 조준과 기존 상하 동작
- **Chosen**: P1의 `T`/`G`, P2의 위/아래 방향키를 상하 조준과 기존 점프/플랫폼 통과에 함께 사용한다. 위쪽 조준 입력에 의한 점프도 허용한다.
- **Rationale**: 별도 조준 키를 추가하지 않고 익숙한 방향 입력을 유지한다.

## D04. 동시 키 입력 문제 진단 및 대응
- **Chosen**: 입력은 문자 표시값 대신 물리 키 코드(`KeyboardEvent.code`)를 기준으로 처리하고, 플레이어별 조작 키를 재설정할 수 있게 한다.
- **Rationale**: 코드에서 서로 다른 키 입력을 덮어쓰는 오류는 발견되지 않았다. P2 방향키와 P1 키를 함께 누를 때의 누락은 키보드의 동시 입력 제한일 가능성이 있으므로, 물리 키를 식별하고 기기에서 인식 가능한 키 조합으로 바꿀 수 있게 한다.

## D05. 조작 키 설정 범위와 저장
- **Chosen**: 좌우 이동, 점프, 플랫폼 통과, 로프, 당기기를 두 플레이어 모두 재설정할 수 있게 한다. 설정은 현재 브라우저에 저장하고 기본값 복원 기능을 제공한다.
- **Rationale**: 키보드마다 인식 가능한 동시 입력 조합이 다르므로 플레이어별로 안정적인 배치를 찾고 이후에도 유지할 수 있어야 한다.

## D06. 조작 키 중복 방지
- **Chosen**: 이미 다른 동작에 배정된 키는 재배정하지 못하게 하고, 해당 키가 사용 중임을 안내한다.
- **Rationale**: 중복 배정으로 두 동작 또는 플레이어 입력이 의도치 않게 함께 발생하는 것을 방지한다.
